# Copy-Paste Link Shortcut Extension

A browser extension that lets you copy predefined links using shortcut commands like `/github`, `/linkedin`, etc.

## Features

- Command-based shortcuts
- One-click copy to clipboard
- Customizable shortcuts
- Works in form fields with auto-suggest

## Installation

1. Download or clone this repository
2. Open `chrome://extensions/` in Chrome
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extension folder

## Usage

1. Click the extension icon
2. Type a shortcut (e.g., `/github`)
3. Press Enter or click Copy
4. Paste the link anywhere

### Default Shortcuts

- `/github` - https://github.com
- `/linkedin` - https://linkedin.com
- `/twitter` - https://twitter.com
- `/portfolio` - https://example.com
- `/email` - developer@example.com
- `/resume` - https://example.com/resume.pdf

## Customization

Click the settings icon in the popup to add, edit, or remove shortcuts.
